# SONUS_Lunchspot_Marker

This little webservice is meant for small teams who regularly go for lunch in a large lunch venue. It solves the problem that teams who are split up during food pickup and checkout in the lunch venue can find each other again by checking the position of the first person who has found a free table that offers enough space for the whole team.
Usage of the service: after deploying the service to a webserver any user can call the URL of the service. In the webbrowser a venue map is shown. By clicking any point on the map in the webbrowser a red dot including a timestamp is placed on the map. This placemark is visible live to any user who accesses the website.
